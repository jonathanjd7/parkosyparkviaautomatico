🚀 GOBARAJAS - INICIO RÁPIDO EN NUEVO ORDENADOR
=====================================================

📋 REQUISITOS PREVIOS:
- Windows 10/11
- Python 3.7+ (https://www.python.org/downloads/)
- Google Chrome instalado

🔧 INSTALACIÓN AUTOMÁTICA (RECOMENDADA):
1. Copiar toda la carpeta "parkosyparkviaautomatico" al nuevo ordenador
2. Abrir carpeta y ejecutar: configurar_nuevo_ordenador.bat
3. Seguir las instrucciones en pantalla
4. ¡Listo para usar!

⚡ INSTALACIÓN MANUAL (ALTERNATIVA):
1. Abrir terminal/cmd en la carpeta
2. py -m pip install -r requirements.txt
3. py -m pip install psutil pywin32
4. Editar gobarajas_config.env (establecer contraseña)
5. Probar: py monitor_gobarajas.py

🎯 USO DIARIO:
- INICIAR: Start-Process -FilePath "py" -ArgumentList "gobarajas_final_clean.py" -WindowStyle Hidden
- VERIFICAR: py monitor_gobarajas.py
- DETENER: taskkill /f /im python.exe

📊 FUNCIONAMIENTO:
- Se ejecuta automáticamente cada 30 minutos
- Importa reservas de Parkos y Parkvia
- Funciona en segundo plano (modo headless)
- Genera logs detallados

🆘 PROBLEMAS COMUNES:
- "py no reconocido" → Reinstalar Python con PATH
- "No module named selenium" → py -m pip install -r requirements.txt
- "Contraseña incorrecta" → Verificar gobarajas_config.env
- "Múltiples procesos" → taskkill /f /im python.exe
- "ChromeDriver error" → Remove-Item -Recurse -Force "C:\Users\%USERNAME%\.wdm"

📁 ARCHIVOS IMPORTANTES:
- gobarajas_final_clean.py (automatizador principal - VERSIÓN MEJORADA)
- gobarajas_config.env (contraseña y configuración)
- iniciar_automatico.bat (script de inicio)
- verificar_estado.bat (verificar estado)
- monitor_gobarajas.py (monitor detallado)
- configurar_nuevo_ordenador.bat (instalación automática)

✅ VERIFICACIÓN DE FUNCIONAMIENTO:
1. Ejecutar: py monitor_gobarajas.py
2. Debe mostrar proceso python.exe ejecutándose
3. Logs deben actualizarse cada 30 minutos
4. Archivo gobarajas_final_clean.log debe crecer
5. Mensaje: "2/2 actualizadores completados"
