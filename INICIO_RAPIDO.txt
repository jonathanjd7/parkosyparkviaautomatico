🚀 GOBARAJAS - INICIO RÁPIDO EN NUEVO ORDENADOR
=====================================================

📋 REQUISITOS PREVIOS:
- Windows 10/11
- Python 3.7+ (https://www.python.org/downloads/)
- Google Chrome instalado

🔧 INSTALACIÓN AUTOMÁTICA (RECOMENDADA):
1. Copiar toda la carpeta "automatico" al nuevo ordenador
2. Abrir carpeta y ejecutar: configurar_nuevo_ordenador.bat
3. Seguir las instrucciones en pantalla
4. ¡Listo para usar!

⚡ INSTALACIÓN MANUAL (ALTERNATIVA):
1. Abrir terminal/cmd en la carpeta
2. pip install -r requirements.txt
3. Editar gobarajas_config.env (establecer contraseña)
4. Probar: python monitor_gobarajas.py

🎯 USO DIARIO:
- INICIAR: Doble clic en "GoBarajas Automatizador" (escritorio)
- VERIFICAR: Doble clic en "Verificar GoBarajas" (escritorio)  
- DETENER: taskkill /f /im pythonw.exe

📊 FUNCIONAMIENTO:
- Se ejecuta automáticamente cada 30 minutos
- Importa reservas de Parkos y Parkvia
- Funciona en segundo plano
- Genera logs detallados

🆘 PROBLEMAS COMUNES:
- "python no reconocido" → Reinstalar Python con PATH
- "No module named selenium" → pip install -r requirements.txt
- "Contraseña incorrecta" → Verificar gobarajas_config.env
- "Múltiples procesos" → taskkill /f /im pythonw.exe

📁 ARCHIVOS IMPORTANTES:
- gobarajas_final_clean.py (automatizador principal)
- gobarajas_config.env (contraseña y configuración)
- iniciar_automatico.bat (script de inicio)
- verificar_estado.bat (verificar estado)
- monitor_gobarajas.py (monitor detallado)

✅ VERIFICACIÓN DE FUNCIONAMIENTO:
1. Ejecutar: verificar_estado.bat
2. Debe mostrar proceso pythonw.exe ejecutándose
3. Logs deben actualizarse cada 30 minutos
4. Archivo gobarajas_final_clean.log debe crecer

🌐 URLs QUE AUTOMATIZA:
- Parkos: https://gobarajas.com/app/actualizadorParkos.php
- Parkvia: https://gobarajas.com/app/actualizadorParkvia.php
